# 应用场景

- 示例一

```
很多客户问我，包一条整整四十尺的大柜子到美国要花多少钱运费？

它能装多少方货物？可以装什么？

今天是一个美国洛杉矶的客户，包了整整四十尺的柜子，来看一下它到底有哪些东西？

这柜子到哪里了？ 美国洛杉矶。

像这个四十尺的柜子大家可以装六十五个方的货物，像这种家具、建材全都可以装。

全是室内装修家具、板材、木材、木椅、饭桌。

如果想从国内邮寄各种家具、建材，或者到美国洛杉矶、华盛顿等城市都会走我们的包柜，也可以走我们的拼柜。

像这样一个柜子到美国也就八九万块钱人民币，直接派送到家，双清包税。
```
