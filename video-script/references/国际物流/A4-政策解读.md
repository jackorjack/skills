# 政策解读

- 示例一

```
东莞企石模具厂的老板请注意！近期模具出口到墨西哥的运费是有所下滑的。在6月底前，船东的运费较6月初的运价是下调的，下调幅度是非常猛的。如果近期有货物要出口到墨西哥，可以抓紧在6月底之前出运，到了7月，有可能运费又会有一个反弹。
```

- 示例二

```
标题：6月航运涨价潮 各大船司齐涨价

文案：6月起全球航线运费暴涨，船公司疯狂加收旺季附加费，航运市场迎来新一轮涨价潮。MSC,马士基，赫伯罗特，达飞等船公司宣布自6月15日起上调多条航线FAK费率，并加征旺季附加费（PSS）。

远东至北欧、地中海航线涨幅最高达2000美元/柜，南美、非洲航线同步跟涨，马士基对远东至南美西岸征收1000美元/40尺柜PSS，达飞对亚洲至北欧航线加收250美元/TEU。

近期，船公司接连推出涨价策略，试图以此稳住运价，建议货主尽快锁定舱位，优先安排高价值货物出货，避免6月下旬运价进一步攀升。关注我们，了解更多资讯。
```
