# 服务流程

- 示例一

```
外贸出口大件设备，特种柜完整流程。

第一次走特种柜的老板们，不知道流程，不仅要多花钱而且还会耽误时间。

今天我带大家来走一遍。

首先不管您是挖掘机还是大型工业机械，第一步就是要上门测量尺寸，把设备的尺寸、重量、重心、不可拆卸的突出部位确认好，必须要精确到毫米。

这一点据称很多老板不在意，报的尺寸会有误差，最后柜子装不下，运费直接翻三倍。

确认好尺寸之后就需要定制最优的柜型，开顶柜或平板柜。

怎么装能最大化的利用空间，把费用降到最低？

大件设备通常都超高、超宽，所以一般会选用超低平板车，把设备运到堆场做专业的捆扎、固定。

接下来就是报关、报检、放行、装船。

通常为了节约时间和顺利通行，会做预报关，包括目的港的清关和派送。

有可能会需要做一些港口和路况的报批，送到指定的地点直到卸货、签收，才算完成任务。

你了解了吗？
```
