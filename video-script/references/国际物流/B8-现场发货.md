# 现场发货

- 示例一

```
师傅正在装柜，这一柜就是发往美国的。你们猜一下这一柜发往美国运费要多少钱？

客户包了一整条柜，害怕政策出问题，叫我们赶快给他发货。我给客户安排的是佛山到美国的海派专线，而且只要1500每方，双清包税，上门安装，还帮你清理垃圾。

师傅这边正在装柜，大家可以看一下，四十尺的高柜，师傅们合理安排，排布位置，使整个集装箱的容量达到最大化。客户买了一别墅的家具，像这种昂贵易损坏的物品，我们会按照国际最高标准给您打包发货。如果您收货之前有任何的问题，我们会进行全额赔付。

等货物到了当地以后，我们还有当地的团队为您服务，直接帮你上门派送安装，而且垃圾帮你清理掉，帮你省掉一大笔的人工费用。我们每周都会有不定量的整柜或者拼柜发出，如果您也有货物需求，赶紧给我点个关注。
```

- 示例二

```
每月装两百多条柜子的蓝牛东莞仓库长什么样？

这边是仓库的工作人员正在卸货，昨天已经到了货物，都是已经打好了木架的。

大家可以看一下整个包装，这边有几条非常大的货物，这边都是家具，都是给货物打了木架的。

像这一条就是发往美东的货物，物流轨迹是可以实时追踪的。

比较重的货物是打了木箱的。

现在到仓库的里面，大家可以看一下目前仓库的货物是非常非常多的。

大家看一下这一票货打的非常的漂亮，这个木箱的包装。

等一会仓库师傅就会将这件货物用油叉，叉入集装箱当中。

你看，大概有两个我这么高了。
```

- 示例三

```
哈喽，加拿大海运超大件的老板看过来。今天发货的是多伦多的这些家具，还有这些日用品，正在装柜的现场。这些货物到达仓库之后，发货之前统一会检查货物是否有破损，易碎的会打上木箱和木架。这些日用品会缠上防水膜打上绑带。

货物到达加拿大之后，万无一失。客户选择的是海卡渠道，双清包税派送到门，时效在40天左右，客户在家里等着收货就可以了。

这些所有的货柜开始准备装柜，发往加拿大，小伙伴们忙起来。
```
