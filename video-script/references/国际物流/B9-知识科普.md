# 知识科普

- 示例一

```
美国整柜DDP运输具体有哪些费用?

这里我给大家整理了一份美国整柜DDP全流程的费用项目，希望大家看完之后能对DDP有一个清晰的了解。

首先就是国内拖车费，也就是国内工厂装完柜之后拉到就近的出货港口这一段产生的运输费用。

第二项就是报关费，从国内正规出口报关费就不必多说了。

第三项就是港杂费，比如从上海洋山港出口中间会产生操作费、文件费等这些费用。

第四项海运费，从国内的出口港到国外的目的港的海运费用。

第五项清关费，船到目的港之后委托当地的清关行帮忙清关要支付给清关行的服务费。

，第六项税金，也就是整柜货物过了美国海关需要交的关税、增值税这些。

第七项目的港的港杂费，其实跟国内的港杂费差不多，也就是拆箱费、换单费、文件费等。

第八项国外的拖车费，在目的港清完关要提柜派送到客户的收件地址，拖车和派送费用都包括。

在这里面记住这8项费用，那您就对美国整柜DDP有了一个大概的了解了。
```

- 示例二

```
一台挖掘机发到非洲，海运费得多少钱?

这是今天的一个粉丝询价，他想发一台挖掘机从上海到非洲西部的安哥拉。

挖机的型号是三一的245，长宽高的尺寸大概就是10米乘3米1乘3米2，体积大概就是100方，重量只有25吨。

重量和体积相比哪个大按照哪个计算运费，当然他的挖机没有超过28吨，所以没有那个重吊费，我们就不考虑。

然后从上海到非洲的安哥拉的海运费大概是70美金一方左右，重点说明一下不同的货物放在不同位置以及不同的发货期，价格差距是非常大的，所以价格仅供参考啊，不要抬杠！

我们只是大概估算一下价格，所以我们就按照70美金一方来算。

那么海运费就是100方乘70美金，大概就是7000美金，按照现在7.1的汇率折合成人民币大概就是50000块钱左右。

这只是海运费，港口还有各种各样的杂费，差不多也得四五干，港口的杂费是人民币，我们按照多的算，按照5000来算。

那么港口的费用加上海运费大概就是5000加50000，大概就是55000左右。

再次说明一下不同的货物，放在不同的位置，以及不同的发货期，价格都有很大差距，并且海运费的价格是每天都在变化，所以价格仅供参考。

如果客户让你说大概的价格，你回复大概五六万左右的样子，这样才比较合适。

近期有计划用散杂船发货的粉丝朋友们都可以找高阳询价，散杂船货代找高阳，省心省事不迷茫。
```

- 示例三

```
二手的挖掘机出口用散杂船发货有2个注意事项。

第1点，如果挖掘机重量超过了28吨，能拆一定要拆到28吨以内。

因为散杂船的货物重量超过28吨，船上的吊可能吊不动，船东可能需要额外租一台重型吊车过来吊，船东就会额外收取重吊费。

关键是重吊费比较贵，可能在1万到2万美金，按照2万美金算都十几万人民币了。拆一次装一次的成本肯定比花重吊费要低得多，所以能拆的一定要拆。像配重、挖斗、大臂、小臂能一下把它拆到28吨以内为止，这样就可能省几万块钱甚至10万元的重吊费。

有人可能抬杠说散杂船中也有重吊船，不想拆给我安排重吊船不就行了吗？问题是重吊船比较少，而且重吊船费用也不便宜，所以还是建议能拆就拆，避免耽搁交货期。

第2点，二手的挖掘机原则上来说没有品牌授权是不允许出口的。但是有些货代就会告诉你说弄个胶带把
logo 和品牌贴一下就行了。

有的商家用黄色胶带贴还能理解，但是有的商家去搞一个黑色的胶带去贴
logo，用黑色胶带去贴和此地无银三百两的张三的做法有什么区别？和掩耳盗铃的李四的做法又有何区别？真是小刀拉屁股开了眼了。

现在管的越来越严了，我建议最好搞一个角磨机把 logo
给抹掉，再买一瓶黄色的自喷漆给它喷一下，不要想着糊弄别人。

出口的整个过程是很麻烦的，找到靠谱的货代，比如我，可以帮你省很多心。
散杂船货代找高阳，省心省事不迷茫。
```
