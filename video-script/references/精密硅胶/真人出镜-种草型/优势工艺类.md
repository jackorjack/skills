# 优势工艺类

- 示例一

```
这个是我们现在正在做的3毫米的硅胶压延片材。
我们这个压延片材是用铂金硫化的，

来看看工艺是怎么样的。
第一道工序就是炼胶，炼完胶以后胶要放到真空机去抽真空，把里面的气泡要抽干。
抽干以后再放到压延机上面去压延，这就是压延机。
胶现在进去了，从这里看，这是五辊压延机，压出来以后这边是厚度，就是3毫米的均匀的厚度。
通过烤箱烤完以后再收卷。
```

- 示例二

```
你知道普通车间跟十万级的无尘车间的区别吗？
我现在手上拿的这个产品是一个儿童音响上面的装饰线，它这个装饰线对外观的要求很严，它的表面不能有黑点，不能有杂质。如果放在普通车间是做不出这个效果来的，所以必须要把它放到十万级的无尘车间里面来生产。
这个产品是呼吸机上面用的硅胶鼻塞套，这个产品要求是医疗级的，所以必须要放到十万级的无尘车间里面来生产。
这个产品是一个车灯的密封圈，这个产品的客户对外观要求其实也是比较严的，所以这个产品也是放在无尘车间里面来生产。
十万级的无尘车间所有的环境都是在封闭的环境下面的，它要求所有的进风和出风都是在密闭的环境下面，包括人员的进出。
要求所有的人都要穿戴好防护服，戴好帽子，穿好鞋子。
现在你知道十万级的无尘车间跟普通的车间区别了吗？
```
