# 应用场景类

- 示例一

```
现在很多的饮水机都要搭配这种硅胶管使用。很多客户的关注点都在机器的本身，它的外观、它的功能性、它的材质等等。其实管材才是直接接触水的一部分，所以这根管的质量的好与坏会直接影响水质会不会受到污染。如何选择一个合格的或者符合健康饮水标准的管其实也很简单，一个小妙招。
第一个看透明度，这种食品级的硅胶管适合婴儿奶水材料，类似的它的透明度很高。这一根就是一个非常劣质的水管，它的很混沌，非常混浊。
第二个一拉就可以了，这种比较劣质的水管一拉里面都是纯白色的。这种食品级的硅胶管随便怎么拉也不会变色，这也是一种小妙招。
第三个可以剪一段用打火机烤一下，这种劣质的管会有冒黑烟，这种基本上是它的残留物都是白色的粉末状的，没有一些黑色的物质。
这种小妙招大家可以关注一下，一个小管大用处。
```
