# 人设类

- 示例一

```
我是佛山快印玉姐，来自湖南新化洋溪镇，在佛山开门店、开工厂，做xx二十五年了。
这是我自己的xxx工厂，目前在佛山有十家xx店。
不知道我们新化老乡还有做什么行业的？如果你刷到了我，欢迎来公司喝茶
```

- 示例二

```
我是陕西安康人，从一无所有到现在我们有自己的工厂，在广东立足，整整花了12年。
这一路走来太多故事，能让我坚持下来的就是陕西人的那股不服输的劲儿，有路过我们公司的陕西老乡，欢迎来我这里做客，我请你吃最正宗的陕西菜，既然刷到也是缘分，我们就认识一下。
```


- 示例三

```
男：这是我老公。
女：这是我老婆。
男：我们都是化州人。
女：我们在东莞寮步做金属检测机、检重秤、异物X光机。
男：我们在东莞创业深耕了18年。
女：我们都是草根出身，白手起家，经历了风风雨雨。
男：我们广东超强科技从30平方做到目前7000平方的规模。
女：我主要负责公司的技术研发和团队管理。
男：我主要负责财务与销售。
女：我们一起经历过人生的高低起伏。
合：我们夫妻同心，其利断金。
女：期待刷到视频的朋友们点个爱心支持一下。

```
