# 噱头故事

- 示例一

```
这是中国最贵的纸箱，光是成本，我们就花到了3600，但是可以给他省到1万以上的成本。
他买直播间的隔音舱将近2万块，用我们的纸箱才3000多块。
我们给他设计的很简单，四片纸拼接回去组装这一个活动型的直播间，房子在哪里都可以去直播，你看这个门，我们以前给他做了个改良，两边都是空气流通，也是经过我们客户的一些需求，给他们独立的设计。
```

- 示例二

```
你肯定没有见过这么奇葩的纸箱，这竟然是用来装家具的。
我们给它设计了用脚蹬的方式，既保持了叉车搬运的功能，又方便人工装卸。
客户之前是用一个托盘放在上面打包，现在改用四个脚蹬结构，用螺丝固定后外面用牛皮胶覆盖防止摩擦。
这样既美观又实用，你看倒过来就能把托盘省下来，操作简单又方便。

```
