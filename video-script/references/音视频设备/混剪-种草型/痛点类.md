- 示例二

```
搭建指挥所是不是每次都要拉上所有设备，人仰马翻？不一定，我们把它做成了模块化积木，任务多大带多少，任务多急开多快，不浪费一个人，不浪费一分钟。三个真实场景，你看差距有多大？
第一，开设二十人以上的基本指挥所。三个显示模块，一个核心模块，一个会议模块，一个服务器模块，两个信息处理模块，三个坐席节点，二十个席位终端，十个话筒，四个音箱，大大小小十三个箱子。四个人二十五分钟全要素开设，全系统运行。
第二，开设十人以内的方向指挥所。两个显示模块，一个核心模块，一个会议模块，同样五个话筒，两个音箱，两个人二十分钟到位。
第三，只开设会议功能的前线指挥所。一个显示模块，一个核心模块，一个会议模块，再加五个话筒，两个音箱，两个人十分钟搞定。 这就是模块化的意义，需要什么带什么，按需搭配，丰俭由人。便携式指挥中心就找军途智联。
```
