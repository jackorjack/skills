# 行业揭秘

- 示例一

```
为什么大型项目用传统铁皮风管的越来越少？
其实很简单，传统铁皮风管不耐火，要额外做防火包覆，时间一长就开裂、剥落。
所以现在项目都直接用一体化防火风管，让系统更稳定。
```

- 示例二

```
为什么高端会议室用传统分体式设备的越来越少?
其实很简单，独立矩阵、处理器、中控一大堆设备堆在一起，品牌不同兼容性差，调试复杂还经常出问题。
现在项目都直接用音视控一体机，一台替代三台，4K60不黑屏。
```

- 示例三

```
为什么应急指挥现场用传统固定式设备的越来越少?
其实很简单，传统机柜设备繁多，布线复杂，一场活动光搭建调试就得两三个小时，撤场更麻烦。
现在应急现场都直接用手提箱指挥系统，十五分钟搭建，双备份不宕机。
```

- 示例四

```
为什么高端项目用传统串口控制屏的越来越少?
其实很简单，传统串口屏编程复杂，需要专业工程师写两遍代码，系统封闭没法装第三方应用，硬件基于消费电子不耐用。
现在项目都直接用工业安卓屏，标准86盒安装，POE供电一根网线搞定。
```
