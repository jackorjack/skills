# 爽点类

- 示例一

```
有什么设备可以让你投标的时候稳操胜券？有什么设备可以让甲方觉得物超所值？
有什么设备可以让甲方觉得这是一个高科技产品？所以我们设计了音视频管理一体机。 
音视频管理一体机是把集中控制功能和高清无缝视频切换功能以及音频处理器的功能集成在一个机箱里面。
这个一体机压缩了不必要的功能，减少了体积，节省了成本。
而且在前面板可以操作整个机器的所有的功能，这样就提高了易用性。 
我们有三款音视频管理一体机，这些设备能够卖出去都是因为帮客户投标，然后中标了，客户才采购的。
第一款音视频管理一体机是一个 7U 的机器，这个设备叫 MX-VM 3800，它包含了一个完整的中控和一个 16 进 16 出的高清无缝混插矩阵，以及一个八进八出的音频处理器。我们这个音频处理器也是可以扩展成十六进十六出，然后它还包含了一个可以灵活扩展的扩展卡槽，可以放上数字功放或者是 POE 的交换机，以及单体的音频设备等等。在前面板有一个 7 寸的触摸屏，这个 7 寸的触摸屏是可以编程的，然后和内部的中控连接起来，控制机箱里面的所有的设备。
第二款的音视频管理一体机是一个 4U 的设备，包含了一个完整的中控，一个八进八出的高清混插视频矩阵，一个八进八出的音频处理器。当然这个音频处理器也是可以扩展成十六进十六出。
第三款音视频管理一体机是一个标准的中控加上一个八进八出的音频处理器，它只有 2U 的机箱大小，所以非常方便。
大家需要了解更多的细节，可以在评论区留言或者是私信给我，谢谢大家点赞关注。
```
