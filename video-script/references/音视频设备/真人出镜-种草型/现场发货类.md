# 现场发货类

- 示例一

```
我身后的这批风管，马上漂洋过海送到阿尔及利亚。 
这一批风管是角铁法兰风管，它不但要满足日常的送排风要求，还要满足强度和耐腐蚀的要求。 
这个板材我们用的是 275g 锌层的板材，这个法兰的锌层厚度在 100um 以上，保证了它的强度和耐腐蚀要求。
为了避免生产过程中产生划痕，我们在地面上全部铺设棉毡，所有操作都在棉毡上完成，确保风管的完整性。 
考虑到这批风管是通过海上运输，面临强腐蚀性环境，我们在风管表面涂了一层油，然后用自吸膜把风管全部包裹起来，避免运输过程中对产品的腐蚀。
每节风管上都有标签，上面有产品尺寸和安装区域，确保产品到了客户手里，能通过分解图纸快速安装，提高安装效率和准确性。
装箱环节是我们专门定制的包装箱，保证每一个系统的精准容纳。在装风管之前，我们会在箱底铺一层棉毡，保证风管的完好性。
从材质的把控到防腐的处理，从编号标识到包装箱的定制，我们全程为产品保驾护航。
屏幕前的老板们，有需要风管的可以联系我们。
```
