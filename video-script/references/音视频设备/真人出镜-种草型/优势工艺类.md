# 优势工艺类

- 示例一

```
像这样的三折叠的手机你见多了，今天带大家来看一下三折叠的LED屏。
来给大家折给大家看一下，来折~看我们这个三折屏啊展开来就是一个135寸，物理尺寸有多少呢？3米长，1.6875米高。
我们这种为什么要做成三折叠呢？是方便我们在多空间里面来进行比如说上下电梯啊房间不够宽啊，直接折一下推到空间里面去然后再推出来到另外空间非常的方便对吧。
我们不单可以折叠，我们这个支架还做了升降的结构，给大家展示一下我们的升降能力，就这遥控器一按，看它往上升了啊，好再来一下，看它是不是在往下降。
它为什么要做升降呢？就为了更方便的去进入我们的所有的房间里面，你再也不用担心门的高度不够我这块大屏进不去你的房间。屏的厚度只有不到15公分，多轻巧多方便，搞完活动开完会打包带走。
这样的三折屏你想不想来一块？

```
