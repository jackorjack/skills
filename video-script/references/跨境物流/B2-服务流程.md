# 服务流程

- 示例一

```
标题：中国到美国发货流程

如果你想把货从中国→美国，但是不知道怎么安排，或者不知道从哪里找靠谱的国际物流公司，那么认真看完这个视频，如果你选择跟我们公司合作的话呢，我们这边会有一对一的客服，根据您的货物情况以及对时效的要求，提供专属您的运输定制方案。如果您觉得时效还有价格都可以接受的话，就把货物寄到我们的深圳仓库这边，我们仓库收到货之后呢，就会帮您安排称重打包，去除多余的重量，然后确认最终的那个计费重量，您确认没有问题的话我们就安排寄出。寄出之前呢，这边会有一个运输资料需要您填写，如果您不知道怎么填写的话，我们这边会有客服一对一的指导，提供模版，您按照这个模版填写就好，然后是付一个运费，接下来就是坐等收货就行。下个视频告诉你从中国运输到美国需要多少钱。
```
