## 何时使用
用户要求生成真人出镜或混剪短视频脚本。

## 核心原则
- **抖音适配**：15-45 秒，开场 3 秒必须有钩子
- **参考风格不照抄**：学习模板的节奏感、口语化、冲突感、结构，融入企业实际信息

## A1 行业热点：搜索规则（强制）

用户选择 A1（行业热点）时，先按本规则取热点，再读模板动笔。本规则对所有企业通用，不绑定任何具体行业或公司。

1. **先定行业，再定词**：从企业资料里取出两样东西——①企业自己所属的行业（决定热点的搜索范围）；②企业提供的产品/服务与服务环节（决定搜索词）。把「行业名 + 服务环节词」组合成搜索词，
   行业名和环节词都来自该企业资料，不引用其他行业、别家公司的内容。
2. **按企业所属行业搜，不按客户所在行业搜**：客户所在行业的景气数据是需求背景，不是本企业的行业热点。搜回来的内容必须落在本企业所属行业及其服务环节上；落不到就换词重搜。
3. **可用性判定**：拿到一条热点先问「它属不属于本企业所处行业、并且落在本企业实际提供的服务环节上？」两问都过才用；过不了就弃用，不要靠编因果把周边行业的数据扭成本行业热点。若确实
   需要引用客户行业数据，必须紧跟一句本行业落点（供给、价格、时效、交付能力的变化），落点补不上就换回本行业热点。
4. **可搜方向**：按本企业的行业与服务环节现场生成 6–10 个方向词，不要套用固定清单。通用拆法：供给端（产能/运力/库存/人才）、价格端（报价/成本/费率/附加费）、规则端（政策/新规/标准
   /认证/管制）、需求端（下游行业动向，仅作背景）、事件端（突发/事故/通道中断/旺季）、竞争端（格局变化/新进入者）——每个方向都要能落回本企业的服务内容。
5. **核验与标注**：不凭记忆写「最近」「新规」，先 `web_search`（带 freshness）核验；每条稿开头标一行「热点依据：来源+日期+数据点」。政策类区分「拟议」与「已生效」，口播保留「拟」>字。
6. **一条一个落点**：每条稿只放一个外部数字，另配一句本企业能力（资质/规模/交付周期/保障率/经验年限等，取自企业资料），把热点翻译成客户下一步动作，不停留在新闻复述。

## 读模板

用户选择选题后，**只加载对应文件**。

**模板目录选择逻辑（行业优先 → public 兜底）**：

1. 从企业行业/产业信息中提取关键词（如「制造业 — 鞋材 / 功能鞋垫 / 足部护理」→ 关键词：`鞋材` `功能鞋垫` `足部护理` `制造业`）
2. 遍历 `references/` 下的子目录，用关键词与目录名做模糊匹配，找到匹配度最高的行业目录（如 `references/国际物流/`）
3. 若行业目录下存在目标模板文件，则**从行业目录加载**
4. 若行业目录不存在或无对应模板文件，**降级到 `references/public/` 加载**

**路径规则**：
- 优先路径：`references/{行业目录}/{选题编号}-{选题名称}.md`
- 降级路径：`references/public/{视频形式}-{类型}/{选题名称}.md`

**匹配逻辑**：模板文件名 = `{选题编号}-{选题名称}`（如选题 A1「行业热点」→ `A1-行业热点.md`，选题 B2「痛点」→ `B2-痛点.md`）。选题编号和名称严格来自上方选题表。
