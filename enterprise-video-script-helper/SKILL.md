## 何时使用（触发条件）

- 用户要求「生成脚本」「写脚本」「做一个视频脚本」「原创脚本」

### 读取企业资料（记忆优先 → 文件兜底 → 同步兜底）

**核心原则：优先从 memory 检索，避免重复加载大文件，命中即用。**

执行顺序：
1. **memory_search 检索**：用以下 query 组合并发检索企业信息（`corpus=memory`），每轮至少 3 条 query：
   - `"企业名称 品牌定位 核心业务 产品线"` → 获取企业基础信息和产品线
   - `"技术壁垒 核心性能 适用场景 用户痛点"` → 获取产品卖点和行业信息
   - `"客户案例 服务数据 行业影响力 竞争优势"` → 获取信任背书和案例
   - 若企业有明确行业关键词（如"鞋垫""机械设备"），追加 `"{行业关键词} 产品 工艺 应用场景"`
2. **memory_get 补全**：检索命中的片段若被截断（含"…"），用 `memory_get` 按路径+行号拉取完整内容
3. **文件兜底**：若 memory 未命中或内容明显不足（少于 3 条有效信息片段），降级读取 `workspace/wiki/` 目录下 md 文档
4. **同步兜底**：若 workspace/wiki/ 目录下无文档，执行技能 `enterprise-kb-sync` 将企业知识库同步到本地，同步完成后回到步骤 1 重新走记忆检索

**注意**：
- memory_search 返回的 `snippet` 可能不完整，关键信息必须用 memory_get 补全
- 不要仅凭 memory_search 的 snippet 判断信息充足，需确保读取到完整段落
- 企业 wiki 文档已自动索引到 memory，优先走记忆通道

### 企业及产品梳理（自动输出）
生成四部分：

**1. 用户分析**（按产品线/行业拆分）

每个行业输出表格：应用场景 | 用户痛点 | 业务优势 | 用户爽点
- 场景要具体（谁+什么情况+需要什么）
- 痛点要量化（数字+对比+后果）
- 优势要差异化（对应痛点的独特方案）
- 爽点要可感知（省了/赚了/解决了什么）
- 每个行业3-5个场景，自动扩展补充

产品分类术语自动选择：制造业→产品系列/产品线，电商→商品类目，服务→服务类型/解决方案

**2. 产品卖点梳理**
每类产品：应用场景 | 核心卖点 | 差异化卖点 | 口语化传播话术

**3. 企业优势梳理**
企业实力 | 信任背书 | 可包装方向 | 其他优势（可搜索补充）

**4. 产品关键词**

产品关键词 = 产品实体本身的名称、品类、材质/材料、功能特征、适用人群/场景词。从产品线名称和产品功能描述中提取，而非从企业优势/业务模式中提取。

**禁止混入以下五类词汇**（与行业无关，任何制造业企业均适用）：
- ❌ 业务模式词：源头工厂、OEM、ODM、代工、贴牌、定制、私模、来图来样
- ❌ 认证/资质词：各类行业认证、检测标准、专利数量（这些是企业优势，不是产品词）
- ❌ 渠道/市场词：跨境、爆款、出口、电商平台名、渠道名
- ❌ 品类概括词：过于宽泛的行业大类词（如"足部护理"应拆成具体产品词"矫正器""分趾器"）
- ❌ 企业属性词：工厂、供应商、品牌方、源头、厂家

**自查方法**：输出产品关键词后，逐条问——「这个词能不能直接描述"你卖的是什么产品"？」不能就删掉。

### 选题
展示选题类型,不要省略，不准省略遗漏，**每个选题根据企业实际生成1个贴合的选题**,表格格式：
|编号|选题方向|选题|

```
🔵 引流型（易爆流量）
A1 行业热点 | A2 老板人设 | A3 行业揭秘 | A4 噱头故事 | A5 国产崛起

🟢 种草型（获客种草）
B1 客户案例 | B2 痛点爽点 | B3 证明实力 | B4 应用场景 | B5 优势工艺 | B6 设备实力 | B7 现场发货 | B8 生产流程 | B9 产品展示

🔴 转化型（获客转化）
C1 业务介绍 | C2 价格优势 | C3 独特优势

🟣 自定义选题：直接输入方向
```

### 读模板
用户选择后，**只加载对应文件**。

**模板目录选择逻辑（行业优先 → public 兜底）**：

1. 从企业行业/产业信息中提取关键词（如「制造业 — 鞋材 / 功能鞋垫 / 足部护理」→ 关键词：`鞋材` `功能鞋垫` `足部护理` `制造业`）
2. 遍历 `references/` 下的子目录，用关键词与目录名做模糊匹配，找到匹配度最高的行业目录（如 `references/鞋垫/`）
3. 若行业目录下存在对应的 `{视频形式}-{类型}/` 子目录且包含目标模板文件，则**从行业目录加载**
4. 若行业目录不存在或无对应模板文件，**降级到 `references/public/` 加载**

**路径规则**：
- 优先路径：`references/{行业目录}/{视频形式}-{类型}/{选题名称}.md`
- 降级路径：`references/public/{视频形式}-{类型}/{选题名称}.md`

**匹配逻辑**：模板文件名 = 选题名称（如选题「老板人设」→ `老板人设.md`，选题「痛点爽点」→ `痛点爽点.md`），无需额外映射。


### 生成完整方案

#### 大字报模式
大字报撰写步骤：
```
第一步：写第一句，第一句的核心是吸引大众好奇，文案是情绪词/噱头词/类型强调的重点，是完整的表达，是可独立的表达，是简短的表达，字数控制在2-10个之间。比如震惊！暗访！暗访xx工厂！万万没想到！又发货了！又爆单了！惊呆了！老美被中国xx（产品）征服！等等。
第二步：第二句需要接住第一句，继续讲。比如：暗访xx工厂，竟发现xx；同理，第三句要接着第二句，第四句要接住第三句。
第三步：继续目标群体完善大字报5句话，注意：每一句都是完整表达，不是一个词语就是一句话；
第四步: 在大字报文案里加入<产品关键词>。
第五步：检查：① 每个大字报是否对目标人群讲？② 每个文案是否包含产品关键词，其次客户人群关键词？③ 大字报文案是否含有数据（阿拉伯数字），抓住用户眼球？④ 内容是否脱离事实？⑤ 有噱头的表达是否前置在第一句和第二句。不满足重新生后,在自查,依次循环直达满足.没问题后，可输出
```

#### 真人出镜/混剪模式
1. **视频文案（分段+纯文案）**：15-45秒，抖音快节奏，开场钩子+痛点共鸣+方案输出+行动号召。提供分段文案（带时长）+ 纯文案
2. **9个视频标题（表格）**：揭秘式 | 利益式 | 悬念式 | 数字式 | 对比式 | 好奇式 | 专业式 | 故事式 | 痛点式
3. **分镜脚本（表格）**：景别 | 画面内容 | 台词/字幕 | 时长 | BGM/音效 | 拍摄要点
4. **封面方案×2**：每个含封面文案+设计建议+图片提示词（中文）

## 核心原则
1. **抖音适配**：15-45秒，开场3秒必须有钩子
2. **参考风格不照抄**：学习模板的节奏感、口语化、冲突感、结构融入企业实际信息
3. **标签**: 标签需要围绕品牌关键词、产品关键词、行业关键词、人群关键词来写

## 输出内容结构(严格遵守)

输出格式：
- 非大字报
```
# {企业名称} - {视频形式} - {选题名称} 完整方案
## 选题策划
## 完整视频文案
## 视频标题
## 话题标签
## 分镜拍摄脚本
## 视频封面建议
```
- 大字报
```
# {企业名称} - {视频形式} - {选题名称} 完整方案
## 选题策划
## 视频文案（≤100字）
## 话题标签
## 视频封面建议
```

大字报的视频文案格式规则（严格遵守）：
1. 第1-2行写2个短句（每句独占一行）
2. 第2-3行之后必须插入1个空行
3. 空行后再写3个短句（每句独占一行）

输出格式示例：
```
不出镜！
吸塑厂老板拒绝出镜

员工抓拍工作日常配音混剪
照样月询盘翻3倍
企盛1对1定制方案 不出镜也能获客
```
