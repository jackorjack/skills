# 实力类

- 示例一

```
我们的客户都是做车载镜头的，有全球第一大、第四大、第五大、第六大的这种客户。
其实对我们的客户而言，客户的要求也彼此有不同。
比如在尺寸的精度上面，他们的要求就不同。还有在材料的选择上面，也有可能不同。
所以应他们不同的要求，我们就会去调制不同的配方来满足他们的需求。密封圈的尺寸的精度要求非常高。
车载有专门一条线。因为车载有30%的产出都是供给车载客户，后段的全制程都在十万级的无尘车间里面完成。
```

- 示例二

```
在云南前五名的纸箱工厂长什么样？
今天来大家看一下我们的工厂。
首先来到的是原纸区，我们的库容量目前是6000吨，可以满足不同幅宽不同的用纸需求。
全自动的富力生产线，两米五的幅宽，三个人就可以完成纸板生产，目前也是国内现代化程度比较高的企业了。
再看我们这边的印刷机，五台印刷机，两条联动线，两个机械手臂日产能60到100万只，一边生产，一边装车在我们这里就可以实现。
如果你有纸箱定制的需求，不管是快递箱，生鲜箱，鲜花箱，茶叶箱还是其他的各类纸箱，都随时欢迎你到厂参观。
```
