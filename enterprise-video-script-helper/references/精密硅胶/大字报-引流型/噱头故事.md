# 噱头故事

- 示例一

```
山东兄弟俩嗅到商机

堆垛整齐 插脚美观 果断先上一条回去生产
```

- 示例二

```
深圳一包租公去收租
不料被一台CCD视觉检测设备吸引

当场给开五金厂的儿子买了十台

还可以24小时不停机一月
可以节约人工成本百分之80
```
