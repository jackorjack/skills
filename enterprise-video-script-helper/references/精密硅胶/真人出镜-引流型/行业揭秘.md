# 行业揭秘

- 示例一

```
中国白酒看河南，河南白酒看郑州，郑州白酒看百荣。
这里是全国最大的白酒批发市场，也是全国最大的白酒集散地。
俗话说：没有百荣卖不到的地方，也没有百荣打不下来的价格。
大概每年 300 亿的白酒都是从这里流向全国各地。在我们省内物流费2-3块钱一件，省外也就 5-8 块钱一件。
所以白酒的价格也低于全国其他同行。
```
