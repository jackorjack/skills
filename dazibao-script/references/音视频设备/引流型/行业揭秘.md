# 行业揭秘（A3）

## 底层逻辑

**揭秘钩子制造信息差 → 抛出反常现象/黑马/成本疑问 → 让目标人对号入座 → 拆内幕/给真相/算成本 → 证据/证言/数据背书 → 价值落点 → 行动出口**

## 爆点类型

曝光爆点、婚礼/场景反差爆点、黑马爆点、工厂火了爆点、客户证言爆点、成本拆解爆点、别被坑爆点、内幕价格爆点、供应链揭秘爆点、工艺揭秘爆点、选品揭秘爆点、渠道揭秘爆点、资质揭秘爆点、交付揭秘爆点、库存揭秘爆点、服务揭秘爆点、对比揭秘爆点、名单对号爆点。

## 位置规律

- **第1句**：揭秘钩子——"我要曝光/杀出黑马/千万别被坑/行业秘密"；
- **第2—3句**：反常现象或疑问，制造信息差；
- **中段**：拆内幕、给真相、算成本、列证据；
- **后段**：证言/数据/资质/保障；
- **结尾**：低门槛行动出口——咨询定制、找工厂、算运费、领清单。

## 结构延伸树（框架不变，只换爆点和变量）

- **曝光场景型**：我要曝光→某场景竟用X→内幕真相→证言→行动
- **黑马工厂型**：行业杀出黑马→某工厂火了→客户证言→数据→找工厂
- **成本拆解型**：大吨位/大订单发往某地→运费/成本多少→费用拆解→别被坑→算成本
- **价格内幕型**：同样产品价格差几倍→内幕在哪→拆成本/工艺→价值→咨询
- **供应链揭秘型**：你以为X→其实来自X→供应链真相→证据→合作
- **工艺揭秘型**：行业常用X→我们/这家用Y→效果差异→参数→看样
- **选品揭秘型**：爆款背后不是玄学→选品逻辑→数据→清单→咨询
- **渠道揭秘型**：同款不同渠道差多少→渠道内幕→保障→行动
- **资质揭秘型**：低价背后缺什么→资质/售后内幕→正规保障→合作
- **交付揭秘型**：为什么有人总延误→交付内幕→自有/直连/库存→订舱/下单
- **库存揭秘型**：找货难真相→库存/品类内幕→当日发→看库存
- **客户证言型**：客户一句话→为什么一直用→证据→行动
- **对比揭秘型**：旧方案vs新方案→差在内幕→数据→换方案
- **名单对号型**：做X的注意→这些坑→拆解→方案→行动
- **避坑拆解型**：千万别被坑→费用/工艺/资质拆解→总成本可控→咨询

## 可复用公式（20条）

### 曝光场景型
我要曝光！【地域/场景】竟然用【产品】做【用途】。当事人：【证言】。各种【品类/定制】都有。
（爆词：我要曝光+竟然；爆点位置：第1—3句）

### 黑马工厂型
杀疯了！【地域/行业】杀出一匹黑马，这家【工厂/品牌】火了。客户：一直用他家【产品】，【效果证言】。
（爆词：杀疯了+黑马+火了；爆点位置：第1—2句+证言）

### 成本拆解型
千万别被坑！【X】吨发往【地点】，运费到底多少？【费1】+【费2】+【费3】，这笔账要算清。
（爆词：千万别被坑+这笔账要算清；爆点位置：第1—3句）

### 价格内幕型
说个内幕！同样【产品】，为什么价格差【X】？内幕就在【成本/工艺/渠道】。扒开算，你就知道该选谁。
（爆词：说个内幕+扒开算；爆点位置：第1—2句）

### 供应链揭秘型
圈内人才知道！你以为【产品】都来自【A】，其实很多来自【B】。供应链真相是【内幕】，证据可查。
（爆词：圈内人才知道；爆点位置：第1—2句）

### 工艺揭秘型
今天不藏了！行业常用【旧工艺】，这家偏用【新工艺】。差别在【参数/效果】，样品可对比。
（爆词：今天不藏了；爆点位置：第1—2句）

### 选品揭秘型
我敢说！【行业】爆款不是靠运气，选品内幕就三点：【点1】【点2】【点3】。想要清单直接问。
（爆词：我敢说；爆点位置：第1—2句）

### 渠道揭秘型
别只看报价！同款【产品】不同渠道差多少？内幕在【渠道/服务/售后】。算总成本，别算单价。
（爆词：别只看报价；爆点位置：第1—2句）

### 资质揭秘型
小心！低价背后可能缺【资质/售后/保障】。正规【服务】要看【证据】，别等出事才后悔。
（爆词：小心；爆点位置：第1句+中段）

### 交付揭秘型
为什么你的货总延误？交付内幕在【自有/直连/库存】。我们做到【保障点】，当日可【交付】。
（爆词：为什么你的货总延误；爆点位置：第1句疑问+第2句内幕）

### 库存揭秘型
别再一家家问了！找【品类】这家宝藏公司【上千库存/品类齐全】，当日发货，售后有保障。
（爆词：别再一家家问了；爆点位置：第1—2句）

### 客户证言型
客户原话！【证言】。为什么一直用【产品/服务】？因为【证据/保障】。
（爆词：客户原话；爆点位置：第1句证言+第2句证据）

### 对比揭秘型
太离谱了！旧方案 vs 新方案，差的不只是价格。内幕在【效率/成本/安全】，数据摆出来。
（爆词：太离谱了；爆点位置：第1—2句）

### 名单对号型
注意啦！做【品类/航线/场景】的，这几种情况最容易被坑：【名单】。拆解给你看，方案直接领。
（爆词：注意啦；爆点位置：第1—2句名单）

### 避坑拆解型
别再被坑了！【费用/工艺/资质】拆开看：【项1】【项2】【项3】。总成本清晰才可控。
（爆词：别再被坑了；爆点位置：第1—2句拆解）

### 婚礼/场景曝光型
你敢信？【场景】竟然用【产品】招待【人群】。当事人：【证言】。定制【品类】都能做。
（爆词：你敢信+竟然；爆点位置：第1—2句）

### 行业黑马证言型
炸了！【行业】黑马【品牌/工厂】火了！不是广告打得多，是【客户证言】。数据/库存/资质可查。
（爆词：炸了+火了；爆点位置：第1—2句）

### 大订单算账型
这笔账要算清！【大数量】发往【地点】，运费怎么算？【费1】+【费2】+【费3】，别等报价单出来才发现被坑。
（爆词：这笔账要算清+被坑；爆点位置：第1—3句）

### 内幕一句话型
行内人告诉你！【行业】最大的内幕：不是【表面因素】，而是【真实因素】。看懂这一点，少花冤枉钱。
（爆词：行内人告诉你；爆点位置：第1—2句）

### 直接行动型
水太深！别自己猜。【产品/服务】内幕、费用、库存、资质，直接问我，给你拆明白。
（爆词：水太深；爆点位置：第1句+后段）

## 原始示例

- 示例一
```
我要曝光
苏州的一对新人婚礼上

尽然用娃哈哈结婚定制水
招待亲朋好友
```

- 示例二
```
广东茶饮圈杀出一匹黑马
广西这家冷冻果汁工厂"火了"

客户：一直用他家的果汁
做出来的果茶口感很好
老板：好的原料才能做出好的果浆
```

- 示例三
```
光学精密配件长啥样？
以前这一个小小的东西
跟国外买要一个月
几千美刀

现在再也不用看别人脸色了
站起来，才能走出去！
```
