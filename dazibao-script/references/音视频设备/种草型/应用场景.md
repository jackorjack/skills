# 应用场景

- 示例一

```
四川一高中引用无感考勤系统
一台摄像头就能无感刷脸考勤

无感刷脸考勤 防止漏打卡
老师:管理更方便了
校长:能够用于全校
包括校门的车辆识别、刷脸

```

- 示例二

```
会议室中如何将多台电脑
传输上70米外显示大屏出图?

支持“按键”选择任意一个信号源
上大屏显示出图，4K30高清画质

```
