## 何时使用
- 用户要求「大字报」
- 用户要求生成大字报短视频脚本、大字报文案。


## 核心原则
- **参考风格不照抄**：学习模板的节奏感、冲突感、结构，融入企业实际信息
- **标签**：围绕品牌关键词、产品关键词、行业关键词、人群关键词来写

## 前置检查

** 检查企业信息是否已梳理**

- 若本轮对话中已执行 `enterprise-profile` 并输出了「企业信息梳理」结果 → 直接跳到「选题」
- 若尚未执行 → 先调用 `enterprise-profile` 技能完成企业资料梳理，拿到结果后再继续

## 读模板

用户选择选题后，**只加载对应文件**。

**模板目录选择逻辑（行业优先 → public 兜底）**：

1. 从企业行业/产业信息中提取关键词（如「制造业 — 鞋材 / 功能鞋垫 / 足部护理」→ 关键词：`鞋材` `功能鞋垫` `足部护理` `制造业`）
2. 遍历 `references/` 下的子目录，用关键词与目录名做模糊匹配，找到匹配度最高的行业目录（如 `references/鞋垫/`）
3. 若行业目录下存在对应的 `{类型}/` 子目录且包含目标模板文件，则**从行业目录加载**
4. 若行业目录不存在或无对应模板文件，**降级到 `references/public/` 加载**

**路径规则**：
- 优先路径：`references/{行业目录}/{类型}/{选题名称}.md`
- 降级路径：`references/public/{类型}/{选题名称}.md`

**匹配逻辑**：模板文件名 = 选题名称（如选题「老板人设」→ `老板人设.md`，选题「痛点爽点」→ `痛点爽点.md`），无需额外映射。

## 生成文案

### 大字报句式要求
**大字报生成的是4-6个短句**
- 第一句：核心是吸引大众好奇，文案是情绪词/噱头词/类型强调的重点，是完整的表达，是可独立的表达，是简短的表达，字数控制在2-10个之间。比如震惊！暗访！暗访xx工厂！万>万没想到！又发货了！又爆单了！惊呆了！老美被中国xx（产品）征服！等等。不要直接出现客户的行业
- 第二句：第二句要接住第一句的词继续讲下去。比如：`暗访xx工厂，竟发现xx`
- 第三到最后一句：要第二句能接住第一句一样，后面的每一句能接住前面的一句
- 大字报中的每一句都是完整的表达，不是一个词就是一句话

### 参考词
- 大字报的第一句的噱头词可参考`references/dazibao-hotword.md`,不要全部用孤立的使用`震惊`,`真相`,`揭秘`等词"

### 违规词(文案内容中不要出现以下违规词)
- 私信

## 不同选题类型生成的要求
- 行业热点: 需要联网去搜索行业相关的热点话题,必须是最近一年内的新闻
- 实力类: 要包含知名案例，规模，产量，大的数据;要少讲专业认证、专利、证书
- 老板人设类: 需要跟企业的创业故事和人设理念相关, 不要虚假捏造,根据企业的实际情况编写
- 成功案例类: 生成的内容用多种不同的结构,不要一直用同一种结构,保证多样化
- 行业揭秘类: 行业揭秘类的合规资料揭秘类型少讲
- 痛点爽点类: 交期不作为痛点爽点讲,流量相关的要说流量稳不稳定,不要说漂移
- 真人出镜应用场景: 是b端客户的使用场景
- 应用场景类: 改成一个文案只聚焦一个应用场景,不要出现多个场景的介绍

### 大字报生成要求

- 交期不作为卖点讲,例如：需要`45`天、等`12`天就送到
- 不要出现术语（如:1.5%、8%、±0.02mm），不讲`数据漂`等这种抽象的表达,用户听不懂，改成普通观众看懂的大白话，不需要用另一个词去解释一个词,保留1-2个直观数字，直白表达文案
- 在大字报文案里加入<产品关键词> ,其次<客户人群关键词>,强制包含产品关键词：`硅胶管`
- 文案要确定是否是对<目标人群>讲？
- 文案要包含有数据（阿拉伯数字），抓住用户眼球
- 有`情绪`/`噱头`/`类型强调`的表达是否前置在第一句和第二句
- 内容不能脱离企业事实，胡编乱造
- 不要出现企业品牌的名称
- 文案里要讲给客户带来什么好处，例如：成本砍半/省几十万，不等料/准时交/不误工期，售后零纠纷/客诉少了99%

### 生成文案自查
生成的文案按照`大字报生成要求` 逐条检查是否满足要求，不满足要求的文案重新生成后在输出，不满足的不允许被输出


## 其它要求
- 每次使用本技能输出最终文案后,在输出全部完整的`选题`

## 输出格式

```
# {企业名称} - 大字报 - {序号}·{选题方向} 
## 视频文案（≤100字）
## 话题标签
（围绕品牌关键词、产品关键词、行业关键词、人群关键词）
## 视频封面建议
（封面文案+设计建议）
```

大字报的视频文案格式规则（严格遵守）：
1. 第1-2行写2个短句（每句独占一行）
2. 第2-3行之后必须插入1个空行
3. 空行后再写3个短句（每句独占一行）

## 输出示例
```
不出镜！
吸塑厂老板拒绝出镜

员工抓拍工作日常配音混剪
照样月询盘翻3倍
企盛1对1定制方案 不出镜也能获客
```
