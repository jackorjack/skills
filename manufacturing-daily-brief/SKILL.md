# 制造业每日资讯推送

> 首次运行自动生成关键词并缓存 → 后续每日定时任务直接用缓存搜索 → 去重 → 推送。关键词只生成一次。搜索严格限定最近 24 小时。

## 触发条件

用户说"每日资讯""行业热点推送""制造业日报""今日速递"等，或通过 cron 定时触发。

## 架构

```
首次运行（手动或自动）
  ├─ 读取企业画像 → 生成关键词 → 缓存到 memory/
  └─ 执行一次搜索 → 推送首期日报

后续每日 cron 定时触发
  ├─ 读取缓存关键词
  ├─ 并行搜索（freshness="day"，仅最近24小时）
  ├─ 去重比对
  ├─ 有新内容 → 按渠道格式推送
  └─ 无新内容 → 静默跳过
```

## 执行流程

### 阶段一：初始化（仅执行一次）

**触发条件**：`memory/daily-news-keywords-{企业简称}.md` 不存在

#### 步骤 1：读取企业画像

1. `memory_search` 检索企业名称、主营产品、行业定位
2. `memory_get` 读取 MEMORY.md 中的公司事实
3. 检索 `wiki/` 目录下的企业资料

提取字段：企业名称/简称、主营产品、行业、目标市场、所在地区

#### 步骤 2：生成关键词并缓存

基于企业画像，自动生成四类关键词，写入 `memory/daily-news-keywords-{企业简称}.md`。

关键词重新生成：企业信息变更时，删除 `memory/daily-news-keywords-{企业简称}.md`，下次执行自动重新生成。

### 阶段二：每日执行（cron 定时触发，每天执行）

#### 步骤 0：检查执行状态

读取 `memory/daily-news-state-{企业简称}.md`：

| 场景 | 行为 |
|------|------|
| 今日首次执行 | 走完整搜索流程 |
| 今日已执行过 | 走增量流程（仅推送新增，无新增则静默跳过） |

#### 步骤 1：读取缓存关键词

直接读取 `memory/daily-news-keywords-{企业简称}.md`，提取所有关键词。

#### 步骤 2：并行搜索（严格限定最近 24 小时）

**所有关键词统一使用 `freshness="day"`**，即只搜索最近 24 小时内发布的内容。

- 每个关键词用 `web_search(query="...", freshness="day", count=5)` 并行搜索
- 16 个关键词分 2 批，每批 8 个同时执行

#### 步骤 3：去重

读取 `memory/daily-news-dedup-{企业简称}.md`，逐条比对 URL：
- 已存在 → 跳过
- 不存在 → 纳入推送，推送后写入

保留最近 30 天记录，超过自动清理。

#### 步骤 4：分类整理

按四类分组，每类取 3-5 条最有价值结果。每条提炼为一句话摘要 + 原文链接。

筛选标准：优先官方来源（gov.cn、news.cn 等）、优先行业直接相关、过滤无关内容、中文 URL 编码处理。

#### 步骤 5：生成日报

#### 步骤 5.5：格式强制校验（推送前必过，不过禁止推送）

推送前逐项核对，**任何一项不合格都必须修正后重做，不得发送**：

1. **分隔线**：一律 `━━━━━━━━━━━━━━━━━━━━`；禁止 `---`、`***`、`===`
2. **链接**：每条新闻必须带原文链接；链接文字**必须含"查看原文"四字**，禁止省略为 `🔗   URL`
3. **时间戳**：底部必须有 `📊   数据截至 YYYY-MM-dd HH:mm`（24 小时制）
4. **四类齐全**：政策风向 / 行业热点 / 外贸动态 / {简称}视角 缺一不可
5. **纯文本渠道**（企微/微信）：禁止任何 Markdown 语法（`**`、`#`、`[链接](URL)`、`>` 引用块）；视角标题与内容**分两行**，禁用 ` — ` 连接（换行会被吞）
6. **Markdown 渠道**（WebChat）：允许加粗与引用块，链接用 `[🔗  查看原文](URL)`

#### 步骤 6：记录状态

1. 更新 `memory/daily-news-state-{企业简称}.md`，记录本次执行时间
2. 更新 `memory/daily-news-dedup-{企业简称}.md`，追加新 URL

## 搜索时间范围规则

| 规则 | 说明 |
|------|------|
| 所有搜索统一 `freshness="day"` | 只取最近 24 小时发布的内容 |
| 不按类别区分时间范围 | 政策、行业、外贸、供应链统一 24 小时 |

## 推送渠道格式

| 渠道 | 是否推送 | 格式 |
|------|---------|------|
| WebChat | ✅   | 格式 A：Markdown（`[🔗  查看原文](URL)` 链接） |
| 企微 | ✅   | 格式 B：纯文本（`🔗   查看原文：URL` 链接） |
| 微信 | ✅   | 格式 B：纯文本（`🔗   查看原文：URL` 链接） |

## 文件清单

| 文件 | 作用 | 生成方式 |
|------|------|---------|
| `daily-news-keywords-{企业简称}.md` | 关键词缓存 | 首次运行自动生成 |
| `daily-news-dedup-{企业简称}.md` | URL 去重库 | 每次推送自动维护 |
| `daily-news-state-{企业简称}.md` | 执行状态 | 每次推送自动维护 |
