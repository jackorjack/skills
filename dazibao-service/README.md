# dazibao-service 维护说明

服务业大字报文案技能（OpenClaw）。本文件给维护者看；agent 只读 `SKILL.md` 和用户选中编号的那份标准。

## 目录约定

```text
dazibao-service/
├── SKILL.md              # 流程和输出格式
├── README.md             # 本文件
└── references/           # 每个选题一份大字报标准
    └── {编号}-{名称}.md    # 如 A1-行业热点.md
```

- 编号前缀不能改：`SKILL.md` 靠 `{编号}-*.md` 找标准。增删选题时同步改 `SKILL.md` 里的选题表。
- 写法规则（位置规律、语言节奏、爆词库）放在各自的标准文件里；`SKILL.md` 只管流程，不重复写。

## 标准来源

| 编号 | 来源 |
|---|---|
| A1 A3 A4 A5 A6、B1—B7、C1 C2 | 《大字报类型标准化条件-全》对应章节原文，只修了转换格式（列表续号、空表头、残留符号、C2 重复的章节号） |
| A2 B8 C3 C4 | 原文档没有，按同结构起草的草案；审定后删掉文件头的「草案」标注 |

文档与选题图的名称对应：

- 人设类 → A3 老板人设类
- 引流 · 国产崛起类 → A6 中国力量类
- 种草 ·「一、国产崛起类」→ B1 客户案例类（原标题笔误，内容是客户案例）
- 产品展示类 → B7 产品展示解说

文档里的现场发货、生产流程、优势工艺三类不在服务业 18 类内，未收录。文档更新后，改对应的 `references/` 文件即可。

## 安装

源码目录不会被 OpenClaw 直接加载，需要时安装到目标 agent：

```bash
openclaw skills install ~/Documents/skills/skills/dazibao-service --agent main
```

改了源码后重新安装，加 `--force` 覆盖旧版本。
