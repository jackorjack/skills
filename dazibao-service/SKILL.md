# 服务业大字报文案

## 1. 先确定出稿标准

- 默认大字报设计：5 句、2+3 排版，上限 80 字。计数包含标点、数字、英文字母、空格和占位符，不计换行。
- 第一句 2-10 字，独立完整，只保留一个与选题有关的利益、反差或悬念；客户行业放到第二句。先内部拟 3 个短开头，选有事实可兑现的一个。
- 第一句与第二句连起来要让目标客户知道「和我有什么关系」。不在开头堆案例名称、比较方案、资质和数字条件。数字利益若无法连同对象及必要限定压进 10 字，整句移到后文。
- 一条只讲一个主利益，保留 1-2 个有依据的直观数字。正文必须包含适配的「公司产品词」{2步整理出来的}；其他技术术语和资质不成串堆入正文。没有数字依据时用明确的待补数值占位，不为凑数字添加无关数据。
- 5 句正文和封面不写品牌名、不用「私信」，结尾按参考文件的「结尾」行写（不一定是一句行动号召）；品牌可放话题标签和企业底稿中。时效可写服务动作与响应速度，不承诺具体到货天数。同批多条时相邻两条结尾句式不得相同（只换名词不算换）。

## 2. 选题

先输出选题表，等用户回编号再往下走：

```markdown
| 引流 · 6 类易爆引流选题 | 种草 · 7 类获客种草选题 | 转化 · 3 类易获客转化选题 |
|---|---|---|
| A1 行业热点类 | B1 客户案例类 | C1 业务介绍类 |
| A2 政策解读类 | B2 痛点爽点类 | C2 价格优势类 |
| A3 老板人设类 | B3 证明实力类 | C3 独特优势类 |
| A4 行业揭秘类 | B4 应用场景类 |  |
| A5 噱头故事类 | B5 服务流程类 | |
| A6 中国力量类 | B6 现场操作类 | |
| | B7 知识科普 | |

回复编号，例如 A1；要多条就加条数，例如 A1 3条
```

- 用户消息里已经带了编号，就不发选题表，直接往下走。
- 编号后面带了条数就出几条，没说就出 1 条。
- 编号对不上，重发选题表。

选定后**只读**这个编号的标准：`/references/{编号}-*.md`（如 A1 → `A1-行业热点.md`）。本轮不打开其他编号的文件，公式、爆词、结尾均取自这一份。

## 3. 检索企业知识库，梳理四部分

用 `memory_search`（带 `corpus=memory`）查询下面的4点信息。片段被截断时用 `memory_get` 读全。

需要具体更详细的信息时从检索片段的源文件读取。

查到的事实整理成四部分，输出：

```markdown
## {企业名称} · 企业信息梳理
### 1. 用户分析
- {客户群体}：{场景}；痛点：{…}；想要：{…}
### 2. 产品卖点梳理
- {产品/服务}：{卖点，有数字就带数字}
### 3. 企业优势梳理
- {优势}：{证据，如年限、规模、资质、案例、数据}
### 4. 企业关键词（品牌 / 产品 / 行业 / 人群）
品牌：… ｜ 产品：… ｜ 行业：… ｜ 人群：…
```

- 每条都必须是知识库里写着的；查不到的写「知识库未提及」。
- 这份梳理是文案的事实底稿：文案里出现的企业事实，都要能在这里找到。
- 同一会话再选题，不重复输出梳理，只补查新选题缺的事实。

## 4. 写文案

**这里很重要！很重要！很重要！强调3遍**

读取的编号标准文件中有的底层逻辑、结构延伸树、可复用公式和案例。 里面的内容是为了让你学习大字报的逻辑是什么，如何延伸结构，有公式和案例供你学习，记住这**不是参考素材，是要你学会应该怎么去写大字报**。你要领悟和学会写大字报文案的精髓。

### 4.1 生成要求

### 根据你领悟和学习到大字报的写法，将{2} 中整理的信息作为数据源开始创作大字报

1. 大字报噱头可以`refences/噱头词.md`中去引用借鉴学习，也可以自己去创建，目的是要能吸引用户看。创作的不够引吸的词就不用了。
2. 生成大字报的内容都是基于企业事实或者联网查询可核实的数据，不是虚构捏造的数据。在保证大字报文案结构的要求事如果企业资料支撑不够，数据不足可以使用【占位符代替】，占位符要说明应该写什么样的数据。
3. 比例统一写成「阿拉伯数字＋%」，不用数字分数、中文分数或「几成」表达：1/4、四分之一写成25%；1/3、三分之一写成约33.3%；两成写成20%。
4. 用户要求某个类型生成多条的时候，生成的文案类型要多样化，不能总写一个结构，一样类似的开头，内容，结尾只是换了个主题词，这种是不符合要求的。一定是要多种结构表达。
5. 当用户要求生成的调试大于编号文件中的可复用的公式时，生成的文案要每个都用到，不够的可自行创作，但是创作也是要满足底层逻辑和结构的延伸。
6. 生成的文案一定要是简单易懂，语句通顺的口语化表达，不要因为字数的限制而节省一个字，将一个完成的词拆开，这是不允许的。
7. A1/A2 为时效选题：先用 `web_search` 搜近 1—6 个月行业热点/政策原文（优先政府站、新华网、协会官网），文案只写搜到的内容；搜不到就写占位符并把依据行标「未核验」。每条开头标「热点>依据：{标题}（{来源}，{日期}）」（A2 写「政策依据」）
8. 生成的文案字数要在80内。不含标点符号和换行，空格
9. 生成的文案要包含{3} 中总结的行业关键词
10. 特殊要求：对A6-中国力量的，不用去读`refences/噱头词.md`，主要是理解，学习，借鉴编号文件中的位置规律要求，结构延伸树 ，可复用的公式来写。理解学习案例的风格，在去生成。
## 11. 输出

- 首次：四部分梳理 + 下面的内容。之后再选题：只出下面的内容。
- 每条是一组：视频文案、话题标签、视频封面建议放在同一个「第 N 条」下面；多条就按组重复。
- 完整选题只在最后放一次，但是是硬门禁必须的。
- 视频封面：封面文案和拍摄建议对得上这条文案。

````markdown
# **当前选题**：{引流/种草/转化} · {编号} · {小类}

## 第 1 条 
**政策依据**：{名称}（{发布机构}，{日期}）　← 只有 A2 有这行；A1 写「热点依据」

### 视频文案
````
