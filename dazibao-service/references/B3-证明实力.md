# B3 证明实力类

【X】都是可替换的变量

## 1、底层逻辑

实力爆词钩子 → 硬实力证据 → 可感知细节/参数 → 第三方反应/客户复购/同行参观 → 承接能力 → 行动出口

## 2、位置规律

- **第1句**：爆词+实力身份——“国内最大/直击/实拍/暗访/万万没想到/全国前三/爆单了/打死不说秘密”；
- **第2—3句**：硬实力证据——产能、车间、份额、年限、代工客户、设备参数；
- **中段**：可感知细节——正在生产、宽幅/速度/成本/秒发/五仓；
- **后段**：第三方反应——老板参观、网友评论、客户复购、大卖整柜；
- **结尾**：承接业务——定制/贴牌/出口/订舱/发样/现货/长期合作。

## 3、结构延伸树：证明实力框架内延伸

框架不变，只换爆点和变量：

1.规模第一型：国内最大→年产能/厂区/研发→稳定供货→合作

2.品牌矩阵型：震惊→研发生产销售一体→多品牌多品类→网友评论→找厂家

3.实拍订单型：实拍某厂→车间等级→客户订单正在生产→下单

4.同行参观型：同行老板集体参观→日产量/设备参数→老板证言→上设备

5.爆款诞生型：又一个爆款诞生→产品火了→商家证言→找货源

6.秘密揭秘型：打死不说秘密→成本/年产/效果参数→看效果→咨询

7.源头工厂型：某地源头工厂→月产能→定制/出口/贴牌→询盘

8.暗访代工型：暗访X年工厂→给X个大牌代工→材质/工艺→找源头

9.排名份额型：全国前三→份额/仓网→一手货源/现货秒发→发样

10.产能反转型：万万没想到→月产能/发运量→全能承接→咨询

11.爆单整柜型：爆单了→首月X条柜→每月Y条柜→订舱

12.硬核物流型：暗访X年物流→500强/箱源→月发运量→订舱清关

## 4、可复用公式（开头全部爆词化）

爆词库： 重磅消息、国内最大、直击、实拍、暗访、万万没想到、全国前三、爆单了、震惊、打死不说、真敢拍、源头工厂、硬核、这家厂藏不住了、客户又复购了、老板集体参观、网友神评、月产能炸了。

1.国内最大型

重磅消息！国内最大【品类】厂，自动化产线年产能超【X】，【厂区数】大厂区旺季稳定供货，【研发/品质】。

2.价格反差型

直击【品类】产线！同样是【产品】，价格却相差【X】倍？来看【车间等级】车间正在生产【高端产品】。

3.品牌矩阵型

震惊！【地域】一【品类】厂家，研发生产销售一体，旗下【品牌数】大品牌，覆盖【品类/包装】。网友：【神评】。

4.实拍订单型

实拍【地域】这家【品类】厂！【车间等级】车间，客户下单的【数量】正在【工序】中。

5.同行参观型

老板集体参观！日产量【X】的【品类】厂，上一台【设备】就够了，【参数】，老板：年产值轻松破【X】。

6.爆款诞生型

【地域】又一个爆款产品诞生！【产品】火了，把【原料/服务】提供给【客户】，商家：省成本稳定高效。你【场景】有用到吗？

7.秘密揭秘型

【地域】【品类】厂打死不说秘密！打印成本才【X】，年产【X】，【X】秒看效果，【性能】。

8.暗访代工型

暗访！【地域】【X】年【品类】工厂，发现给【X】个国际大牌做代工，这【材质/工艺/颜色】太高级！

9.排名份额型

全国前三的【品类】厂！【X%】的【品类】从这里发出，一手货源，【发样/定做/现货/仓网】。

10.万万没想到型

万万没想到！这家【地域】【品类】源头工厂，一个月产能【X】，定制/贴牌/现货全能轻松承接。

11.爆单整柜型

爆单了！【地域】大卖在【平台】联系我，第一个月发了【X】条整柜到【目的地】，现在每月稳定【Y】条柜。

12.硬核物流型

暗访！【地域】【X】年xx，发现给500强企业做运输，这箱源渠道太硬核，月发运【X】吨。

13.产能承接型

直击现场！【品类】工厂【车间等级】车间，月产能【X】，【定制/出口/贴牌】全能接。

14.老板证言型

【客户身份】参观【品类】厂，看完【设备/产线】说：【证言】。年产值/效率轻松破【X】。

15.直接行动型

这家【品类】厂藏不住了！【核心实力证据】，要【定制/贴牌/出口/订舱/看样】，直接问我。
